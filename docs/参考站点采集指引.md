# 参考站点采集指引

远程会话的出网策略拒绝了参考站点（CONNECT 403，非该域名特有，`google.com`
同样被拒），且该站需要登录会话。因此**采集必须在你自己的机器上完成**。

## 用法

```bash
npm i playwright
npx playwright install chromium
node tools/capture_reference.mjs <参考站点的工作台URL>
```

浏览器会打开。手动登录后**正常点击各个菜单**，脚本检测到路由变化就自动采集，
Ctrl+C 结束。产出在 `capture/`：

| 文件 | 内容 | 为什么需要 |
|---|---|---|
| `NN-*.png` | 整页截图（含滚动区） | 布局与视觉参照 |
| `NN-*.outline.txt` | 结构大纲：层级 + 尺寸 + 标题文案 | 栅格与区块划分，截图量不出来 |
| `NN-*.tokens.json` | 设计 token：颜色/字号/字重/圆角/字体，按出现频次排序 | 复刻的关键，肉眼取色必然失真 |

`capture/auth.json` 是你的登录会话，**只留本地，发文件时务必剔除**。

## 需要采集的页面（按优先级）

已知路径（来自你此前提供的截图）：

| 路径 | 页面 |
|---|---|
| `/web/system/home/work-bench` | 工作台 |
| `/web/system/home/space-preview-list` | 空间展示 |
| `/web/system/home/service-device-list` | 设备列表 |
| `/web/system/host-status/dashboard` | 主机状态 |

尚未见过、优先级从高到低：

1. **场景控制弹窗**（空间展示卡片上的「场景控制」）—— 决定中控引擎的建模
2. **设备控制弹窗**（设备列表右侧「控制」）—— 决定指令模板与驱动模型
3. **系统引擎**、**主机管理** —— 完全未知，无从推测
4. 告警中心、工单管理、运维巡检、资产管理、能源管理
5. 会议预约的完整下单流程（选空间 → 选时间 → 邀请成员 → 关联场景）
6. 预约日程、消息中心、AI 速记
7. 各页的空状态、加载态、表单校验错误态（最容易漏做的部分）

弹窗类页面路由不变，脚本不会自动触发——打开弹窗后手动截图即可。

## 复刻边界

结构与交互可以照搬，视觉建议重做。具体地：

**可以复刻**：信息架构、菜单层级、页面栅格、表格列定义、筛选与分页交互、
状态机（告警的待处理/已处理/误报警等）、字段命名。这些属于行业通用做法。

**不要照搬**：产品名与 logo、图标集、空间展示里的实拍照片、以及从页面
导出的 CSS/JS 源码。该系统是本项目的竞品，成品要交付给医院，采购方会做
知识产权审查——视觉与素材照搬是实际风险点，结构照搬不是。
