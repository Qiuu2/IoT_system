# 参考站点采集指引

远程会话的出网策略拒绝了参考站点（CONNECT 403，非该域名特有，`google.com`
同样被拒），且该站需要登录会话。因此**采集必须在你自己的机器上完成**。

## 用法：两步

```bash
npm i playwright single-file-cli
npx playwright install chromium

# 第一步：登录并点一遍，自动采集截图 / 结构 / 设计 token
node tools/capture_reference.mjs <参考站点的工作台URL>

# 第二步：对同一批页面各存一份 SingleFile 完整快照（复用第一步的登录态）
node tools/snapshot_pages.mjs
```

第一步会打开浏览器，**手动登录后正常点击各个菜单**，脚本检测到路由变化就自动
采集，Ctrl+C 结束并写出 `capture/urls.txt`。第二步消费该清单。

若第二步报「Chromium executable not found」，设置 `CHROME_PATH` 指向本机 Chrome：

```bash
# Windows
set CHROME_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
# macOS
export CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

## 产出

| 文件 | 内容 | 为什么需要 |
|---|---|---|
| `NN-*.png` | 整页截图（含滚动区） | 布局与视觉参照 |
| `NN-*.outline.txt` | 结构大纲：层级 + 实际像素尺寸 + 标题文案 | 栅格与区块划分，截图量不出来 |
| `NN-*.tokens.json` | 设计 token：颜色/字号/字重/圆角/字体，按出现频次排序 | 复刻的关键，肉眼取色必然失真 |
| `NN-*.snapshot.html` | SingleFile 单文件快照：渲染后 DOM + 内联 CSS/字体/图片 | 可离线打开、直接量间距取色改样式 |

`capture/profile/` 是登录态，**只留本地，发文件时整个目录剔除**。

## SingleFile 的两个实测限制

**一、脚本会被全部剥离。** 实测本地一个 165 KB 的页面，快照只有 22 KB、
`<script>` 数量为 0。存下来的是「渲染完那一刻的静态 DOM + 内联样式」——
对设计参考是好事（干净、可量、可改），但**不是能跑的应用拷贝**，
点击、弹窗、路由全都没有。

**二、它抓的是快照，不是应用。** 每个想留档的形态都得单独存一次：
弹窗打开时一次、空状态时一次、切到别的 tab 再一次。需要交互才出现的界面，
SingleFile 抓不到，只能在第一步的浏览器里手动触发后截图。

## Node 版本坑

Node 23 之前没有全局 `CloseEvent`，而 single-file-cli 的依赖 `simple-cdp`
直接使用了它，会以 `ReferenceError: CloseEvent is not defined` 崩溃。
`tools/snapshot_pages.mjs` 已内置 polyfill，无需手动处理。

## 需要采集的页面（按优先级）

已知路径（来自你此前提供的截图）：

| 路径 | 页面 |
|---|---|
| `/web/system/home/work-bench` | 工作台 |
| `/web/system/home/space-preview-list` | 空间展示 |
| `/web/system/home/service-device-list` | 设备列表 |
| `/web/system/host-status/dashboard` | 主机状态 |

尚未见过、优先级从高到低：

1. **场景控制弹窗**（空间展示卡片上的「场景控制」）—— 决定中控引擎的建模
2. **设备控制弹窗**（设备列表右侧「控制」）—— 决定指令模板与驱动模型
3. **系统引擎**、**主机管理** —— 完全未知，无从推测
4. 告警中心、工单管理、运维巡检、资产管理、能源管理
5. 会议预约的完整下单流程（选空间 → 选时间 → 邀请成员 → 关联场景）
6. 预约日程、消息中心、AI 速记
7. 各页的空状态、加载态、表单校验错误态（最容易漏做的部分）

弹窗类页面路由不变，脚本不会自动触发——打开弹窗后手动截图即可。

## 复刻边界

结构与交互可以照搬，视觉建议重做。具体地：

**可以复刻**：信息架构、菜单层级、页面栅格、表格列定义、筛选与分页交互、
状态机（告警的待处理/已处理/误报警等）、字段命名。这些属于行业通用做法。

**不要照搬**：产品名与 logo、图标集、空间展示里的实拍照片、以及从页面
导出的 CSS/JS 源码。该系统是本项目的竞品，成品要交付给医院，采购方会做
知识产权审查——视觉与素材照搬是实际风险点，结构照搬不是。
