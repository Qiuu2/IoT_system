# 本平台的招标规格（清单原文）

> 自清单「智能化集成平台」子系统抽取，**未经改写**，是需求与验收的直接依据。


## 427 · 平台基础底座 （1 套）　`清单第 431 行`

综合态势：首页显示各子系统的关键数据，用户可快速掌握建筑的综合态势。综合态势展示的数据依据项目实际接入的系统而定，如环境数据、医疗数据、人车通行数据、能耗数据、工单数据、设备数据。
2）首页视频监控：以图标显示摄像头楼层点位分布，使用不同图标表示不同摄像头类型，通过图标样式区分摄像头是否在线的状态，选择摄像头可查看实时监控画面。


## 428 · 数视融合管理 （1 套）　`清单第 432 行`

1）分层协同架构：1、支持分层架构设计，涵盖数据接入、融合处理等多层体系，确保各层高效协同。
2、支持适配机房、环境监测、梯控等多场景，且便于后续升级扩展。
3、各层间数据流转高效，为整个模块稳定运行提供坚实基础。
2）多源多协议接入：1、支持接入关系型数据库、传感器数据等多源异构数据，兼容 MQTT、HTTP 等多种协议。
2、支持与各类物联网设备、工业控制系统无缝对接，保障数据顺畅进入系统。
3、兼容主流视频流协议，含Onvif/GB28182等，支持主流摄像头品牌，支持私有视频流协议定制。
4、能自动识别数据格式，降低对接复杂度。
3）多元播放与报警：1、支持视频预览、大屏融合播放及分屏播放等多种方式，满足不同展示需求。
2、支持接入外部报警信息，报警触发时通过画面闪烁等方式实时提醒。
3、可自定义报警提醒方式及播放参数。
4）安全运维管理：1、支持按角色分配权限实现用户隔离，完整记录操作日志且存储时长≥2 年。
2、支持设备远程通讯、升级和维护，保障系统安全稳定运行。
3、定期生成安全报告，便于管理系统安全状态。
5）多场景适配扩展：1、支持机房、环境、梯控等场景的数据视频融合，可个性化配置融合方式。
2、支持通过预留接口适配更多行业场景，拓展系统应用范围。
3、针对不同场景提供专属融合模板，加速部署进程。
3年质保


## 429 · 运维物业管理系统（web） （1 套）　`清单第 433 行`

1）综合信息展示：1、系统登录后进入系统综合信息展示页，根据用户角色，首页展示不同的纬度的相关数据。可预览项目基本运维信息，包含基本信息，日常管理记录（报修），最新通知信息，本月工单统计，最新工单记录等。如：系统首页根据用户角色，首页展示不同的纬度的相关数据。如：项目管理员展示基本信息、日常管理、本月工单统计、本月报警统计等相关数据；客服主要展示报修工单等相关数据等
2）报修管理：1、流程引擎：提供较通用报修派单流程配置引擎，可根据项目实际需求，标准化配置项目报修业务流程
2、工单列表：工单消息列表支持查看所有的工单消息，点击可查看工单详情，当前工单的处理状态等信息，工单消息可通过权限设定哪些用户可以查看，可以处理
3、工单处理：工单处理按照流程引擎设定的业务流程流转执行，包括工单创建、分配、处理等环节
3）维保管理：1、维保模板：维保模板依据系统-类别-类型，给不同类型设备配置不同的维保事项，维保事项可以有多个，可以设定维保的周期和维保任务生成提前的天数
2、维保计划：维保计划周期可以分为周保养、半月保养、月保养、季保养、半年保养、年保养、其他等选项，维保计划需要设定计划开始时间，选定设备维保模板，指定计划给对应维保单位等事项，参数设定完成即可创建计划
3、维保任务：计划创建好后，系统依据设定好的维保参数，定时推送指定的任务给到指定的维保班组。任务生成后，便可在维保计划任务列表中查看该条任务的状态和维保完成结果
4、责任班组：支持自定义创建维保班组和对应负责人，班组成员和负责人可在组织架构中自由选择配置
5、外委单位：项目上一些比较特殊的设备，是需要外委单位有特殊资质的专业人员进行维保，此时需要在外委单位栏创建对应的外委单位名称、负责人、联系方式等内容
4）巡检管理：巡检配置：巡检分设备巡检和设备间巡检，巡检开始前首先需要依据系统-类别-类型选择某一类型的设定进行批量配置巡检事项，也可选择单个设备进行巡检设定。巡检配置主要是配置巡检周期和巡检班组。巡检点可以设置多个，可以通过排序号自定义巡检点顺序。巡检点类型分为是否、数字、文本三种类型。填写对应参数即可完成巡检配置
2、巡检任务：巡检配置好后，系统依据设定好的巡检规则，定时推送指定的任务给到指定的巡检班组。任务生成后，便可在巡检任务任务列表中查看该条任务的状态和巡检结果
3、巡检排班：巡检排班支持自定义设置排班起止时间和成员
5）消息中心：1、消息管理：消息管理展示所有的已发送的报警消息和通知消息，支持主动编辑消息发送给指定的组织架构中的人员，同时可以查询历史已发送的消息
2、规则管理：规则管理支持自定义选择规则类型、报警类型、描述内容、发送对象等，规则创建启用后，满足规则设定的条件，即可将消息发送给对应的人员
3、模板管理：模板管理支持用户自定义创建一个消息模板，模板内容包含名称、报警类型、所属规则和内容
4、我的消息：“我的消息”对本人接收到的报警和通知消息进行分类统一管理。报警消息支持跳转至接收到的每条报警消息的详情页（详情页包括报警的基本信息、报警信息、实时情况、相关人员读取和处理状态），并能够进行流程化在线处理，处理每条报警消息之后有处理结果反馈
6）业务报表：报表中心：对于报事、报修不同时间段工单总数、已完成数、未完成数、完成率、未完成率等进行统计，并支持导出；对公区和租区不同时间不同工单状态的工单数量分布进行统一管理并支持搜索查询，导出功能；对报修报表的导出表头可进行模版化配置，根据实际需求选择模版进行导出关注的报表数据
7）基础信息：1、空间类型管理：支持自定义编辑空间类型字典
2、使用类型管理：支持自定义编辑使用类型字典
3、空间管理：对项目的空间信息进行管理，管理内容包括建筑位置信息，可定义每个房间类型。每个房间生成一个二维码，支持在线二维码管理以及在线打印
4、设备管理：对设备的台账进行基础信息的管理，包括对台账信息的增删改查等基础应用操作，支持设备分配到具体操作人员权限划分，支持批量导入,导出、对项目设备中的配套附属设备等进行统一管理、支持在线二维码管理以及在线打印，对智能化和附属设备进行单独统一管理
5、附属设备管理：附属设备管理支持维护设备间的拓扑关系
8）系统管理：1、名称：物业运维管理系统-系统管理
2、项目管理：项目信息管理，自定义编辑项目项目信息，还可以上传项目附件材料
3、角色管理：基于RBAC权限模式，将权限与角色绑定，新增用户时与角色绑定
4、用户管理：初始化、维护管理用户的信息，查看用户的信息
5、部门管理：内部组织架构管理，支持自定义创建组织架构
6、系统日志：对平台中的登录、以及主要功能应用的日常操作（例如：新增、编辑、修改等）进行日志记录查询，具备历史操作回溯能力
3年质保


## 430 · 物业运维管理系统（APP） （1 套）　`清单第 434 行`

1）移动端首页：移动端首页展示当前用户信息，最新任务信息、接收内部通知通告以及重要报警信息的接收等功能。异常报警及消息通知主动推送，智慧建筑态势7*24小时随时随地掌控，可在移动端方便快捷的处理报警情况；每条通知消息支持跳转至对应的工单详情页或者任务列表页面。
2）设备台账：能够利用移动APP扫描设备二维码，查询设备基础信息（系统，分类，品牌，型号，供货商等）、静态属性、设备附件并且可在线查看维护保养记录，巡检记录等。
3）检修报修：能够利用手机APP实现报修，在APP上接单并且快速处理线上报单业务。形成闭环业务处理，并且通过手机APP快速上传设备维修单。
4）设备巡检：设备巡检栏默认展示该用户当前需要处理的巡检任务列表，也可查看历史的巡检任务。支持通过扫一扫直接扫描设备上的二维码，查看该设备的巡检事项并执行巡检任务，也可单击单条巡检任务可去执行，巡检结果支持离线提交。
5）设备维保：设备维保栏默认展示该用户当前需处理的维保任务列表，也可查看历史的维保任务。支持通过扫一扫直接扫描设备上的二维码，查看该设备的维保事项并执行维保任务，也可点击单条的维保任务去执行，维保结果支持离线提交。
6）报警接收：异常报警及消息通知主动推送，智慧建筑态势7*24小时随时随地掌控，可在移动端方便快捷的处理报警情况；每条通知消息支持跳转至对应的工单详情页或者任务列表页面。
7）个人中心：查看当前登录的个人信息，个人密码更改，清除缓存，数据更新，版本检查等
3年质保
