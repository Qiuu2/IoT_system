### 锁定不再质疑的结论

1. **本平台是集成平台，不是各子系统本身。** 摄像机、门禁、照明由各专业厂商供货实施。
2. **三网部署位置是全项目第一架构决策**，早于一切功能设计。
3. **告警必须按 `(设备, 告警码)` 聚合。**【实测】13 条在告故障对应 6,310 次发生；
   不聚合的话一台离线设备按 10 秒轮询一小时产生 360 条。
4. **下行指令由网关轮询拉取，不由平台反向调用。** 理由：适配单向网闸。
5. **可写点位由驱动声明、网关侧兜底拒绝**，不依赖平台自觉。

## 6. 关键教训 / 反模式

| 现象 | 教训 |
|---|---|
| 早期把协议解析写死在采集器里，红外扩展器的 `STAT 0` 被当成"电压 0.0V" | **探测方式与字段必须由驱动声明**，采集器不对任何型号特判 |
| 落盘队列用毫秒时间戳+固定 pid 做文件名，3 次入队只剩 1 个文件 | 同毫秒会覆盖，必须加单调序号并在重启时从磁盘续号 |
| 第一版告警不聚合 | 一台离线设备 10 秒一轮 → 一小时 360 条，告警中心当天报废 |
| 甘特图窄条无标签、最右刻度被裁 | 图表要渲染后看一眼再发 |
| `pkill -f "gateway/main.py"` 把自己的 shell 也杀了 | 用 `[g]ateway` 字符类规避自匹配 |
| 用户多次说"你说清楚一点" | **先一句话结论，再展开**；不要堆架构和代码 |
| EMQX 资料普遍过时 | 5.9.0 起已转 **BSL 1.1**，非 Apache-2.0，商用受限 |

**许可证红线**（均【核实】）：FastBee(AGPL-3.0)、Seatsurfing(GPL-3.0)、Snipe-IT(AGPL-3.0)、
TDengine(AGPL-3.0)、SagooIOT(LGPL-3.0)、unitedrhino/things(仓库标 AGPL 而 README 写 Apache，口径冲突)。
**只可参考设计，不可混入代码。**

**参考站点复刻边界**：结构与交互可照搬（信息架构、栅格、表格列、状态机）；
产品名、logo、图标集、实拍素材、页面源码不可照搬。用户已认可此边界。
