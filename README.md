# IoT_system — 智慧会议物联运维平台

南京市儿童医院河西院区二期项目 · 智慧医院物联运维平台。

需求基线来自两份招标清单：[`全专业清单.xlsx`](./全专业清单.xlsx)（1417 行 / 65 子系统）与 [`清单.xlsx`](./清单.xlsx)（多媒体会议系统 147 行）。
